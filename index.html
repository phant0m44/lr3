MARVINLINK - мій проект

Основна ідея проєкту полягає у створенні автономної, приватної та бюджетної екосистеми для моніторингу параметрів довкілля та керування побутовими пристроями за допомогою штучного інтелекту. На відміну від популярних комерційних рішень (як-от Amazon Alexa чи Google Home), цей проєкт базується на принципах відкритого коду та локальної обробки даних. Центральна концепція розробки — використання архітектури «клієнт-сервер» у межах одного пристрою або локальної мережі. Це дозволяє вирішити головну проблему сучасних IoT-систем: залежність від стабільності інтернет-з'єднання та загрозу витоку персональних даних через постійне прослуховування фонового аудіо зовнішніми серверами. Використання одноплатного комп'ютера Orange Pi Zero 3 у поєднанні з мікроконтролером ESP32 дозволило створити потужний обчислювальний вузол, здатний працювати з мовними моделями без високих витрат на обладнання. Наукова новизна роботи полягає в інтеграції локального двигуна розпізнавання мовлення Vosk із хмарними можливостями ChatGPT API Gemini API.

Про проєкт

  • Автор проєкту - студент
  • Проєкт розробляється як pet-проект у вільний від навчання час
  • Основа — одноплатний комп'ютер Orange Pi Zero 3 та мікроконтролер ESP32
  • Весь код проєкту відкритий і доступний на GitHub

Можливості проєкту

Локальне розпізнавання мовлення
Обробка голосових команд відбувається на пристрої за допомогою рушія Vosk, без передавання аудіо на зовнішні сервери.
Моніторинг довкілля
Збір показників температури, вологості та інших параметрів приміщення через датчики Zigbee.
Керування пристроями
Можливість керувати побутовими приладами голосом або через локальний веб-інтерфейс.
Інтеграція з хмарними LLM
За потреби складних запитів система звертається до Gemini API для генерації відповіді.
